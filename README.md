# Calculadora em Java

Calculadora de terminal que realiza as quatro operações básicas entre dois números.

## Como funciona

1. Digite o primeiro número.
2. Digite o segundo número.
3. Escolha a operação: `+`, `-`, `*` ou `/`.
4. O programa mostra o resultado com duas casas decimais.

A divisão por zero é tratada e exibe uma mensagem de aviso.

## Como executar

Requer o JDK instalado.

```bash
javac Main.java
java Main
```

## Conceitos praticados

- Entrada de dados com `Scanner`
- Tipo `double` para números decimais
- Estrutura `switch`
- Tratamento de divisão por zero

## Exemplo

```
Digite o primeiro número:
7
Digite o segundo número:
2
Digite a operação (+, -, *, /):
/
Resultado: 3,50
```
